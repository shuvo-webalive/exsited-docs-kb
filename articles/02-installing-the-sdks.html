Every Exsited SDK can be installed two ways: from its language's package registry, or straight from its public GitHub repository. Use the registry for released versions, and GitHub for the latest code on the main branch. This article lists both commands for each language.

See the installation guide

exsited-sdk-python		 pip install "git+https://github.com/exsited/exsited-sdk-python.git"

exsited-sdk-js		 npm install github:exsited/exsited-sdk-js

Go
exsited-sdk-go		 go get github.com/exsited/exsited-sdk-go@main

Keeping the SDK up to date

From a registry, update the package with your package manager, for example pip install -U "exsited>=4,<5", npm update exsited or composer update exsited/exsited; for Java, raise the version in your pom.xml. From GitHub, run the same install command again to take the newest commit; for Java and .NET, pull the clone and build it again. Each SDK's changelog on GitHub lists what changed in each release.

Troubleshooting

The package manager cannot find the package

Check the package name for your language: it is exsited in most registries, exsited/exsited on Packagist, Exsited on NuGet and com.exsited:exsited on Maven Central. If you need a change that is not released yet, install from GitHub instead.

Python installs an older SDK

Keep the version range in the install command, "exsited>=4,<5". Older releases of the same package belong to an earlier API.
