The customisation APIs let your software add your own fields and record types to Exsited. You can define custom attributes and attach them to records such as accounts, define custom components and manage their objects, notes, activity, linked records and workflow status, and set up custom features with their own form layout. You can also read your custom fields, manage custom forms and download the file a file attribute holds. All fifty-eight endpoints are available in all seven Exsited SDKs.

Good to know

Replacing links unlinks what you leave out, and status changes run at once

Replace the accounts or orders linked to a component object unlinks every record you leave out of domains, so send the full set. To add one record, use Link accounts or orders to a component object instead. Change a component object's workflow status runs the transition, and any actions the workflow carries, at once.

Component paths take two kinds of id

Creating, updating and deleting a component instance on /component/{component_uuid} take the component's dashed uuid, and those instance bodies use the component's name, such as service_contract, as their key. Every other call takes the definition's cmp_ id, and object calls under /components/ use custom_component_object.

  • Dropdown options go in as strings and come back as objects. Send options as a list of strings; each option reads back with a name and a display_order.
  • The custom feature path is singular. Call /custom_feature. Writes put their fields inside component, and the feature comes back under custom_feature. A custom feature's id starts with cmp_, the same id a component definition has.
  • Component object notes are multipart forms. Put the text in the note field and any files beside it. A file's uuid in attachments is the file_id for the file calls.
  • Only a form that is not system generated can be deleted. is_system_template tells you which custom forms are system generated.
  • Custom fields are read only here. There are no create, update or delete calls for them.
  • Lists come a page at a time. Records come under data. Send limit, then pass the next_cursor from pagination as cursor while has_more is true.
