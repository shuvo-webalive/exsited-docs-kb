The sales APIs let your software handle what your accounts buy and pay for. You can create and change orders, quotes and contracts, record usage on metered lines, raise and amend invoices and pro-forma invoices, record payments, issue credit notes and refunds, and manage gift certificates and sales reps. You can also read credit note applications and list the payments and refunds in a bank reconciliation, though those two lists are not yet confirmed to work. All 165 endpoints are available in all seven Exsited SDKs.

Good to know

Only a preview is a dry run

Only an order path that ends in preview leaves the order as it is. Every other state change, such as upgrade, cancel or discard_draft, changes the order at once, and Discard a draft order removes the draft so it can no longer be read. Preview an order creates no order, but an account object in its body still creates that account. Money also moves for real: Create a payment charges the card when a payment_applied entry names a processor that holds a card token.

Applying a credit note records payments

Apply a credit note to invoices records a payment against each invoice you list in credit_note.invoices, but the call returns the credit note rather than those payments. Each entry takes only invoice_id and amount.

  • Pass an invoice's id, never its uuid. Every invoice path takes the invoice's id, such as INV-0001. An entry in List invoices has no lines; retrieve the invoice, or list its lines, to see them.
  • Most write bodies sit under one key. Orders use order, invoices invoice, payments payment, refunds refund and credit notes credit_note. The order upgrade, downgrade and contract_adjustment calls and their previews are the exception: they take effective_date and lines at the top level.
  • A contract needs a recurring or metered item on a line. Set allow_contract to true and send contract_properties when you create the order.
  • Money mostly comes back as text, and lists come a page at a time. Amounts such as an invoice's total or a refund's amount are strings like "12.00". A credit note application's amount and remaining_balance are numbers. Listings put their records under data. While pagination.has_more is true, send pagination.next_cursor as cursor to get the next page.
  • Reading one invoice line always returns the first line. Retrieve an invoice line ignores the line id, so use List an invoice's lines to find a specific one. Delete an invoice note file currently returns 404 attachment not found, even for a file the note's files listing shows.
  • Creating a sales rep currently fails. Create a sales rep returns 400 validation_error, naming no field, even for a valid body, so you can update and delete only reps that already exist.
