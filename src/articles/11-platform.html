The platform APIs let your software work with your customer portal, your integrations and the data around your Exsited instance. You can log portal users in and manage their passwords, read your integration connections, create external databases and work with their records, and read overview reports over a date range. You can also manage OAuth applications, read the root organisation, manage child organisations and read webhook deliveries. All thirty-five endpoints are available in all seven Exsited SDKs.

Good to know

Some changes cannot be taken back

Set a portal password by email does not ask for the current password, and the old password cannot be put back. An external database cannot be deleted through the API; to put its tables back to a known state, create it again with replace set to true. Creating a child organisation changes your organisation hierarchy and assigns an existing user to it.

Reports can be slow

A report can take up to 90 seconds. Set your client timeout above the default 30 seconds, such as 120. Amounts and counts in a report, such as amount, count and net_gain, are strings, not numbers.

  • A portal user is an account with portal access. Create the account with grant_portal_access set to true and a grant_portal_password, then log in with its email_address and that password. Every portal request body sits under portal.
  • Each external database record is a list of field and value pairs. A record looks like {"record": [{"field": "company", "value": "Acme Pty Ltd"}]}.
  • The client id and secret of a new application are never returned. Exsited generates them, and the API does not return them.
  • Organisation records sit under organization, spelled with a z. The root organisation is read only and never appears in List child organisations.
  • No endpoint lists webhook deliveries. Keep the whk_ id each delivery carries, so you can read it later.
  • External databases page differently. Their listings use has_next, has_prev and per_page; the other listings here send pagination.next_cursor as cursor while has_more is true.
